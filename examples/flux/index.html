Authentification

Le parent s'identifie par son numéro de téléphone. L'opérateur connaît déjà ce numéro, donc le champ arrive pré-rempli et le code à usage unique n'est demandé qu'à la première connexion, ou une fois la session expirée.

Demander un code

Cet appel est fait par la plateforme de l'opérateur, avec son jeton machine.

POST /v1/auth/parent/otp/request
{
  "phone": "+228 90 00 00 09",
  "locale": "fr"
}

Vérifier le code

Le code validé rend une session : un jeton d'accès de trente jours et un jeton de rafraîchissement de quarante-cinq. Le jeton d'accès est celui du parent, et c'est lui qui sert pour tous les appels suivants sauf mention contraire.

Un écran sans ligne d'appel ne déclenche aucune requête : il se contente d'afficher ce que l'écran précédent a déjà chargé.

Apprenants

Un pack porte sur un apprenant et une année scolaire. Le choix du pack se fait à l'ajout de l'apprenant, jamais à la connexion — le parent n'est donc jamais bloqué.

Lister les apprenants rattachés

GET /v1/parents/me/children

Rattacher un apprenant

L'établissement est choisi d'abord, l'apprenant ensuite, le pack en dernier. Les trois étapes sont indépendantes et peuvent être reprises séparément.

La planche suivante récapitule les appels, dans l'ordre où le parent les déclenche.

SCHÉMA D'ENSEMBLE — PLANCHE PAYSAGE

Paiement

Le paiement est accessible dès le pack gratuit. Le parent choisit l'apprenant, puis le frais à régler, saisit le montant qu'il souhaite verser et valide par son code.

Montants partiels

Un versement partiel est toujours accepté. Le reste à payer n'est affiché qu'à partir du pack Basic : en Gratuit, la liste ne montre que le montant du frais.

Reçus

Le reçu est produit à la confirmation de l'encaissement, jamais à la demande de paiement — un paiement accepté par l'opérateur mais non confirmé n'a pas de reçu.
