IBM Plex Sans + IBM Plex Mono

3. Le transport de session

Le jeton d’accès vaut trente jours, le jeton de rafraîchissement quarante-cinq. Le parent n’est jamais bloqué à la connexion : s’il n’a aucun apprenant rattaché, il peut simplement en ajouter un. L’appel se fait avec Authorization: Bearer …, et l’en-tête X-Operator-Id reste obligatoire côté opérateur.

Demander un code

POST /v1/auth/parent/otp/request
{
  "phone": "+228 90 00 00 09",
  "locale": "fr"
}
